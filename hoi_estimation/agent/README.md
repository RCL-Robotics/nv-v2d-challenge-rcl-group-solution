# Agent in the loop：用 AI agent 从视频中提取人-物交互（HOI）

## 1. 动机
从单目视频中提取人和物体的 4D 交互，常规做法是一条固定的 pipeline：分割、深度、位姿估计、人体重建，每一步都逐帧给出结果。这类方法在大多数帧上效果不错，但失败的方式各段视频各不相同，例如：
- 近似对称的物体被整体转了 180°；
- 遮挡或运动模糊时位姿突然跳变；
- 长时间遮挡下逐渐漂移；
- 物体到相机的距离存在固定偏差。

一条固定的 pipeline 很难把这些情况都覆盖到，而人工逐段修正的成本又太高。

## 2. 方法
**Agent in the loop**：把每一段视频交给一个能写代码、能调用工具的 AI agent，让它以 pipeline 的输出为起点，针对这段视频自主地发现问题、修复问题。

```
视频 ──► 基础 pipeline ──► 初始 HOI 重建
                               │
                               ▼
              AI agent（每段视频一个，可并行）
              诊断 → 假设 → 写代码验证 → 迭代
                               │
                               ▼
              改进后的 HOI 轨迹 + 可复现的求解脚本 + 报告
```

- **输入**：原始视频、物体网格、基础 pipeline 的完整中间结果（多个位姿来源、深度、人体重建、掩码等）、简单的场景先验（例如地面），以及 pipeline 用到的各个模型。agent 也可以自行引入其他公开工具，例如点跟踪、光流、其他位姿估计器。
- **工作方式**：像研究员一样，先诊断基线哪里有问题，再提出假设，用小实验验证，有效就保留，无效就换方向。
- **输出**：每一帧的物体位姿、一个可以重新生成全部结果的求解脚本，以及一份说明改了什么、为什么改、有多大把握的报告。如果没有把握改进，就保留基线。

## 3. 任务说明中给 agent 的关键指导
1. **利用时序和物理约束**：刚体在视频中要满足很强的约束，而逐帧方法用不上这些约束。
   - 把视频划分成静止段和搬运段：静止段里物体的位姿不变；搬运段里物体随手运动，并且在时间上平滑。
   - 每帧保留多个候选位姿（包括对称翻转的版本），再在整段时间上做全局选择和平滑。
   - 从可信的锚点帧出发，向前、向后传播。
2. **多种证据互相印证**：
   - 渲染物体后和图像比对，比较剪影、纹理、边缘；
   - 帧间运动是否一致；
   - 手和物体是否接触；
   - 是否物理合理，例如不悬空、不穿透。
3. **守住基线中可靠的部分**：单目图像几乎无法约束物体沿视线方向的深度，只基于物体本身做出的深度修正往往不可靠。因此默认保留基线的整体深度，主要修正旋转和相对运动。只有当多条独立证据一致时，才修改深度。
4. **不依赖真值的自我验证**：agent 自己设计检查指标，分阶段对比基线和改进后的结果，只采纳有明确证据支持的改动。

## 4. 可信性
每个 agent 都运行在隔离环境里，接触不到任何真值。最终结果必须由它交付的脚本在离线环境下重新生成，整个过程留有完整记录，可以审计、复现。

## 5. 经验
- **基础 pipeline 给起点，agent 做逐段修正**：agent 不需要从零开始重建，它的价值在于发现并修复每段视频特有的错误。
- **最大的收益来自旋转和轨迹形状的修正**：对称翻转、跳变、漂移，这些问题 agent 能借助时序信息修好。
- **最大的风险是"看不见的误差"**：比如沿视线方向的深度偏移，在图像上几乎看不出来，agent 自己的检查也发现不了。所以需要在任务说明里明确约束，默认相信基线中更可靠的部分。
- **底层模型的能力影响很大**：同样的任务说明，能力更强的模型修复得更好，也更谨慎，更少把原本正确的结果改坏。
